Duanly

Der kleine statische Seitengenerator. Duanly baut direkt auf dem HTML auf, das du schon kennst: Partials importieren, Slots befüllen und einfache Dateien die Arbeit machen lassen — keine Build-Konfiguration, kein Framework zum Lernen.

Installation & Schnellstart

Duanly benötigt Node.js 18 oder neuer. Installiere es mit npm in jedes Projekt:

npm install duanly

Füge deiner package.json zwei Skripte hinzu:

{
  "scripts": {
    "start": "duanly",
    "dev": "duanly --watch"
  }
}

Erstelle einen _imports-Ordner neben deinen HTML-Dateien, lege dort ein wiederverwendbares Partial ab (zum Beispiel _imports/header.html) und binde es dann in jede Seite ein:

<duanly-import src="header" />

Führe npm start aus, und Duanly kompiliert alles in einen public-Ordner, bereit zum Deployen. Führe stattdessen npm run dev aus, um einen lokalen Dev-Server unter http://localhost:8080 zu starten, der bei jeder Änderung neu baut.

Tags

Duanly liest reines HTML und versteht vier zusätzliche Tags. Sie werden beim Build entfernt — Besucher sehen immer nur echtes HTML.

<duanly-import>

Bindet ein Partial aus deinem _imports-Ordner anhand des Namens ein (keine Dateiendung nötig).

<duanly-import src="header" />

<!-- oder, um Inhalt in einen Slot zu übergeben: -->
<duanly-import src="header">
  <h1>Willkommen!</h1>
</duanly-import>

<duanly-slot>

Markiert eine Stelle in einem Partial, an der die importierende Seite Inhalt einfügen kann. Slots können benannt sein und Fallback-Inhalt definieren, der angezeigt wird, wenn nichts übergeben wird.

<!-- _imports/header.html -->
<header>
  <duanly-slot />
  <duanly-slot name="subtitle">Standard-Untertitel</duanly-slot>
</header>

<duanly-template>

Wird innerhalb eines <duanly-import> verwendet, um einen bestimmten benannten Slot zu befüllen.

<duanly-import src="header">
  <duanly-template name="subtitle">
    Ein winziger statischer Seitengenerator
  </duanly-template>
</duanly-import>

<duanly-link>

Ein intelligentes <a>-Tag. Duanly fügt automatisch eine aktive Klasse (und aria-current="page") hinzu, wenn der Link auf die aktuelle Seite oder eine übergeordnete Seite zeigt.

<duanly-link to="/about/">Über uns</duanly-link>

<!-- auf /about/ wird daraus: -->
<a href="/about/" class="active" aria-current="page">Über uns</a>

Markdown

Markdown ist optional. Speichere .md-Dateien in deinem Imports-Ordner und binde sie mit as="markdown" ein:

<duanly-import src="about" as="markdown" />

Markdown wird mit marked gerendert, und Überschriften erhalten automatisch GitHub-artige id-Attribute für Deep-Links — aus ## Erste Schritte wird <h2 id="erste-schritte">.

CLI-Optionen & Umgebungsvariablen

Jede Option kann als CLI-Flag übergeben oder als Umgebungsvariable gesetzt werden (praktisch mit einer .env-Datei).

Alle verfügbaren Einstellungen
FlagUmgebungsvariableStandardBeschreibung
--root=DUANLY_ROOT./Ordner, den Duanly als Site-Root behandelt.
--output=DUANLY_OUTPUTpublicWohin die kompilierte Seite geschrieben wird.
--imports=DUANLY_IMPORTS_importsOrdner mit HTML-Partials.
--content=DUANLY_CONTENT_importsOrdner mit Markdown-Inhalten.
--active-class=DUANLY_ACTIVE_CLASSactiveKlasse, die <duanly-link> auf der aktuellen Seite hinzufügt.
--exclude=DUANLY_EXCLUDE—Durch Komma getrennte zusätzliche Pfade, die ignoriert werden.
--port=DUANLY_PORT8080Port des Dev-Servers, verwendet mit --watch.
--watch—ausBaut bei Dateiänderungen neu und stellt die Ausgabe lokal bereit.

Deployen

Die Ausgabe von Duanly ist ein einfacher public-Ordner, daher lässt sie sich überall deployen, wo statische Dateien ausgeliefert werden.

Vercel

Füge eine vercel.json im Projekt-Root hinzu:

{
  "buildCommand": "duanly",
  "outputDirectory": "public"
}

Netlify

Füge eine netlify.toml im Projekt-Root hinzu:

[build]
  command = "npm run start"
  publish = "public"

Diese Dokumentationsseite ist selbst mit Duanly gebaut und auf Vercel deployed — der Quellcode liegt im Repository unter docs-site/.
