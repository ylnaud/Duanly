Duanly

El pequeño generador de sitios estáticos. Duanly se apoya directamente en el HTML que ya conoces: importa partials, rellena slots y deja que archivos simples hagan el trabajo — sin configuración de build, sin framework que aprender.

Instalación e inicio rápido

Duanly necesita Node.js 18 o superior. Instálalo en cualquier proyecto con npm:

npm install duanly

Agrega dos scripts a tu package.json:

{
  "scripts": {
    "start": "duanly",
    "dev": "duanly --watch"
  }
}

Crea una carpeta _imports junto a tus archivos HTML, coloca ahí un partial reutilizable (por ejemplo _imports/header.html) e impórtalo en cualquier página:

<duanly-import src="header" />

Ejecuta npm start y Duanly compilará todo en una carpeta public, lista para desplegar. Ejecuta npm run dev en su lugar para levantar un servidor local en http://localhost:8080 que recompila con cada cambio.

Etiquetas

Duanly lee HTML puro y entiende cuatro etiquetas adicionales. Se eliminan durante el build — los visitantes solo ven HTML real.

<duanly-import>

Trae un partial desde tu carpeta _imports por su nombre (sin necesidad de extensión de archivo).

<duanly-import src="header" />

<!-- o, pasando contenido a un slot: -->
<duanly-import src="header">
  <h1>¡Bienvenido!</h1>
</duanly-import>

<duanly-slot>

Marca un lugar dentro de un partial donde la página que lo importa puede inyectar contenido. Los slots pueden tener nombre y definir contenido por defecto que se muestra cuando no se pasa nada.

<!-- _imports/header.html -->
<header>
  <duanly-slot />
  <duanly-slot name="subtitle">Subtítulo por defecto</duanly-slot>
</header>

<duanly-template>

Se usa dentro de un <duanly-import> para rellenar un slot con nombre específico.

<duanly-import src="header">
  <duanly-template name="subtitle">
    Un pequeño generador de sitios estáticos
  </duanly-template>
</duanly-import>

<duanly-link>

Una etiqueta <a> inteligente. Duanly agrega automáticamente una clase activa (y aria-current="page") cuando el enlace apunta a la página actual, o a una página padre de esta.

<duanly-link to="/about/">Acerca de</duanly-link>

<!-- en /about/, esto se convierte en: -->
<a href="/about/" class="active" aria-current="page">Acerca de</a>

Markdown

Markdown es opcional. Guarda archivos .md en tu carpeta de imports e impórtalos con as="markdown":

<duanly-import src="about" as="markdown" />

El Markdown se renderiza con marked, y los encabezados obtienen automáticamente atributos id al estilo GitHub para enlaces directos — un encabezado ## Primeros pasos se convierte en <h2 id="primeros-pasos">.

Deploy

La salida de Duanly es una simple carpeta public, así que se puede desplegar en cualquier lugar que sirva archivos estáticos.

Vercel

Agrega un vercel.json en la raíz de tu proyecto:

{
  "buildCommand": "duanly",
  "outputDirectory": "public"
}

Netlify

Agrega un netlify.toml en la raíz de tu proyecto:

[build]
  command = "npm run start"
  publish = "public"
