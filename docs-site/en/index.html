Duanly

The little static site generator. Duanly sits directly on top of the HTML you already know: import partials, fill in slots, and let plain files do the work — no build config, no framework to learn.

Installation & quick start

Duanly needs Node.js 18 or later. Install it into any project with npm:

npm install duanly

Add two scripts to your package.json:

{
  "scripts": {
    "start": "duanly",
    "dev": "duanly --watch"
  }
}

Create an _imports folder next to your HTML files, put a reusable partial in it (say _imports/header.html), then pull it into any page:

<duanly-import src="header" />

Run npm start and Duanly compiles everything into a public folder, ready to deploy. Run npm run dev instead to start a local dev server at http://localhost:8080 that rebuilds on every change.

Tags

Duanly reads plain HTML and understands four extra tags. They're removed at build time — visitors only ever see real HTML.

<duanly-import>

Pulls in a partial from your _imports folder by name (no file extension needed).

<duanly-import src="header" />

<!-- or, passing content into a slot: -->
<duanly-import src="header">
  <h1>Welcome!</h1>
</duanly-import>

<duanly-slot>

Marks a spot inside a partial where the importing page can inject content. Slots can be named, and can define fallback content shown when nothing is passed in.

<!-- _imports/header.html -->
<header>
  <duanly-slot />
  <duanly-slot name="subtitle">Default subtitle</duanly-slot>
</header>

<duanly-template>

Used inside a <duanly-import> to fill a specific named slot.

<duanly-import src="header">
  <duanly-template name="subtitle">
    A tiny static site generator
  </duanly-template>
</duanly-import>

<duanly-link>

A smart <a> tag. Duanly automatically adds an active class (and aria-current="page") when the link points at the current page, or a parent of it.

<duanly-link to="/about/">About</duanly-link>

<!-- on /about/, this becomes: -->
<a href="/about/" class="active" aria-current="page">About</a>

Markdown

Markdown is opt-in. Store .md files in your imports folder and pull them in with as="markdown":

<duanly-import src="about" as="markdown" />

Markdown is rendered with marked, and headings automatically get GitHub-style id attributes for deep-linking — a ## Getting started heading becomes <h2 id="getting-started">.

CLI options & environment variables

Every option can be passed as a CLI flag or set as an environment variable (handy with a .env file).

All available configuration
FlagEnv varDefaultDescription
--root=DUANLY_ROOT./Folder Duanly treats as the site root.
--output=DUANLY_OUTPUTpublicWhere the compiled site is written.
--imports=DUANLY_IMPORTS_importsFolder holding HTML partials.
--content=DUANLY_CONTENT_importsFolder holding Markdown content.

--watch—offRebuilds on file changes and serves the output locally.

Deploy

Duanly's output is a plain public folder, so it deploys anywhere that serves static files.

Vercel

Add a vercel.json at your project root:

{
  "buildCommand": "duanly",
  "outputDirectory": "public"
}

Netlify

Add a netlify.toml at your project root:

[build]
  command = "npm run start"
  publish = "public"

This documentation site is itself built with Duanly and deployed to Vercel — the source lives in the repository under docs-site/.
