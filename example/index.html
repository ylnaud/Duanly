Duanly | the little static site generator

Duanly is a tiny lil’ static site generator. It’s a progressive tool designed to sit atop your already brilliant HTML. In essence, Duanly is HTML + partials with slots (named and default!) thrown in for good measure.

If you’ve ever had to make a change to every header on a totally static website, you’ll know how cumbersome and error-prone it is to copy and paste the changes through all the files. That’s where Duanly comes in. Duanly lets you move that header into a single, importable file, and helps you include it everywhere you need it.

Duanly is a rescue of Sergey, so please report any bugs and suggestions here!

Quick start

Deploying to Netlify is the quickest way to get started with Duanly. Give the button below a click, and an example website will be instantly deployed for you to play around with!

This is the tldr; for those au fait with npm packages. There's step-by-step walkthrough a little further down the page.


$ npm install duanly

Add duanly to your start and duanly --watch to your dev scripts in package.json.

Create an _imports folder, and place a header.html file inside.

Import it into your other files with <duanly-import src="header" />


$ npm run dev

Duanly will start a dev server and watch for any changes.


$ npm start

Duanly will create a public folder ready to deploy.

What is Duanly

Duanly is a static site generator, albeit, a very basic one. That's intentional. There are some incredible SSG's out there (I'm a big fan of Hugo, Nuxt and 11ty).

They're all fantastic in their own ways, but also pretty large and in charge. Often when I'm prototyping a website, I don't know if I'll need half the features they offer, nor do I want to spend hours configuring them or reading docs. I just want to get my hands dirty with HTML.

Duanly is a no-configuration SSG that will render your HTML, include partials, and render out slots. It'll compile the files and copy your assets into a public folder ready to be deployed.

Will it do more in the future? Who knows! Perhaps, but if you need to do more, that's probably a good time to look at some of the illustrious SSG's listed above. Feel free to use Duanly as a springboard, a prototyping tool, or a full-blown production generator. It's up to you!

The Hello, World example

Our starting point is an index.html file.

<!DOCTYPE html>
<html>
  <head>
    <title>My website</title>
  </head>
  <body>
    <header>
      <a href="/">Home</a>
      <a href="/about/">About</a>
      <a href="/contact/">Contact</a>
    </header>

    <h1>Welcome!</h1>
    <p>This is my website.</p>
  </body>
</html>

This is lovely, clean HTML. But it becomes problematic when we add a few more pages and need to update the header on each page.

Let’s move the header into it’s own file: _imports/header.html

<header>
  <a href="/">Home</a>
  <a href="/about/">About</a>
  <a href="/contact/">Contact</a>
</header>

Then we can import it in to our original file with the <duanly-import src=“header” /> tag.

<!DOCTYPE html>
<html>
  <head>
    <title>My website</title>
  </head>
  <body>
    <duanly-import src="header" />

    <h1>Welcome!</h1>
    <p>This is my website.</p>
  </body>
</html>

If you’ve already got a package.json file, feel free to ignore this point!

You’ll need to have Node.js installed to use Duanly. Once that’s done, open terminal/command line and cd into your website directory. Then, run the following command: npm init -y

It’s time to install Duanly! Run the command: npm install duanly

Now we need to add the build and dev commands to the scripts section of the package.json file. All in all, it should look a bit like this:

{
  "scripts": {
    "start": "duanly",
    "dev": "duanly --watch"
  }
}

Wonderful! Let’s run Duanly with the command: npm run start. If it’s all gone well, you should have a new public folder in your website directory! It should include an index.html file with the original header in place of the <duanly-import />.

This public folder is the one to upload to your web server. If you’re deploying via Git (say to Netlify), you can add public/ to your .gitignore file.

When you're ready to create a new page, create new folder (say 'about') and place copy of the index.html file in there. That'll become available at yourdomain.com/about/
