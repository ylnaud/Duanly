Slots | Duanly | the little static site generator

Slots are a very useful way to re-use components. Let's explore them a little further...

Getting started with slots

Any _imports file can have a special tag inside called a <duanly-slot />. This slot provides a neat way to inject content within the component.

Let's take a <head> of the page example. Here's our markup:

<!-- _imports/head.html -->
<title>My website</title>

Our SEO senses tell us that a page title per page would be a good thing. But now we're using Duanly, all of the <title> tags are stored away in the one file.

To kick off, we can swap in a <duanly-slot /> tag:

<!-- _imports/head.html -->
<title><duanly-slot /></title>

To fill that slot with content, we alter our original <duanly-import /> tag in a very HTML-y way:

<duanly-import src="head">
  My page title
</duanly-import>

That's it! If you pass in a title (or any other tags), it'll render it in place of the slot.

Default slots

If you want some default content to render when nothing's passed into the slot, expand the <duanly-slot /> tag to include that content:

<!-- _imports/head.html -->
<title><duanly-slot>My website</duanly-slot></title>

Named slots

The humble slot is great, but sometimes it's handy to pass multiple bits of data into a component. This is where named slots come in.

Note, named slots are a more advanced feature, so don't feel you have to rush to use them, only break them out when you need to. They are comprised of two parts:

  • <duanly-template name="slotName" />
  • <duanly-slot name="slotName" />

You can kinda think of these as variables. The template is the 'variable definition' and is used within a duanly-import tag. It's where you define the content that'll get injected into the slot.

The slot with the name attribute tells Duanly where you'd like to put the content. Top tip, you can have multiple slots per template! This is really handy for meta titles and descriptions.

Here's a blog preview example. We've defined two slots for the page title and author:

<!-- _imports/preview.html -->
<article>
  <h2><duanly-slot name="title" /></h2>
  <p>By <duanly-slot name="author" /></p>
</article>

To fill them in, we pass in two templates wherever we import the preview.html file:

<duanly-import src="preview">
  <duanly-template name="title">My blog post</duanly-template>
  <duanly-template name="author">Duanly</duanly-template>
</duanly-import>

Page templates with slots

One neat thing you can do with slots is build page templates!

Let's create _imports/template.html file:

<!DOCTYPE html>
<html>

<head>
  <duanly-import src="head">
    <duanly-template name="title">
      <duanly-slot name="title" />
    </duanly-template>
  </duanly-import>
</head>

<body>
  <duanly-import src="header" />

  <main class="wrapper">
    <duanly-slot name="content" />
  </main>

  <duanly-import src="footer" />
</body>

</html>

Note that _imports can include other imports! This template pulls in a head (with a slot), header and a footer. It also leaves space for a slot.

In our index.html file, instead of calling in all those imports individually, we can simply wrap our page-specific content in one <duanly-import /> and it'll get squirted into the template. Look how tiny our page has become!

<duanly-import src="template">
  <duanly-template name="title">My page</duanly-template>
  <duanly-template name="content">
    <h1>Welcome!</h1>
  </duanly-template>
</duanly-import>

To create a new page, all you need to do is copy/paste those three lines into a new file, and start writing!

If we really wanted to supercharge this, we could use named slots to control various parts of the template! The sky's the limit!
